# Тестовое задание — вёрстка страницы с карточками

Тестовое задание на вакансию Frontend разработчик в отдел вёрстки

## Что сделано

- Адаптивная вёрстка по макету (3 разрешения), использован подход mobile first.
- Меню: оверлей на мобильном/планшете, фиксированная колонка на десктопе. Закрытие меню через <kbd>Esc</kbd>
- Карточки:
  - мобильный — 115–150px, квадратные (`aspect-ratio: 1/1`);
  - планшет/десктоп — ширина 128–174px, высота `128px` (по макету).
- Отступы между карточками фиксированы (`gap: 16px`).
- Футер, в мобильной версии в потоке, на планшете/дектопе прижат к низу.
- Анимация: переключения гамбургера между состояниями.
- `prefers-reduced-motion` для анимаций реализован через переменные без `!important`.
- `aria-label` бургера меняется синхронно с `aria-expanded` (`Open menu`/`Close menu`) через JS.
- Доступность: aria-атрибуты, фокус, скролл-лок.

## Как запустить

Установка зависимостей:

```shell
npm install
```

Сборка с минификацией CSS/JS:

```shell
npm run build
```

Режим разработки с live сервером:

```shell
npm run dev
```

Сборка и режим разработки собирают итоговый проект в каталог `./build`.

## Линтеры

- **Stylelint** с плагином `@morev/stylelint-plugin` — проверка BEM-нейминга,
  запрет «внешних» свойств на блоках, порядок свойств. Конфигурация `.stylelintrc.json`.
- **ESLint** — проверка JS, конфигурация `eslint.config.js`

### Исключения для BEM-правил

Плагин `@morev/bem/no-block-properties` запрещает «внешние» свойства (`position`, `top`, `width`, `margin` и т.п.) на уровне блока — по БЭМ блок не должен знать о своём положении в родителе.

Однако `.side-menu` — это оверлей, и `position: fixed` с координатами является его сутью, а не внешним контекстом. Для таких случаев в конфиге добавлено точечное исключение через `allowProperties`:

```js
// .stylelintrc.js
'@morev/bem/no-block-properties': [true, {
  allowProperties: ['position', 'top', 'bottom', 'left', 'z-index'],
}],
```

Это позволяет сохранить строгость правила для компонентов, где позиционирование действительно должно задаваться родителем, и не ломать оверлеи.

## Брейкпоинты

- `< 640px` — мобильный
- `640–1023px` — планшет
- `≥ 1024px` — десктоп

## Принятые решения

### Прозрачность фонов на десктопе

В макете фон элементов задан с прозрачностью 0.4. Чтобы избежать наложения слоёв, задан белый базовый фон на `body` — все
полупрозрачные элементы смешиваются с ним одинаково (`header`, `main`, `footer`).

### Ширина колонок карточек

Использован `minmax(115px, max-content)` + `max-width: 150px` на карточке (мобильная версия). `max-content` как максимум ограничивает колонку «идеальной» шириной контента, которая упирается в `150px`. Это даёт диапазон `115–150px` и ровные отступы `gap` без медиазапросов и JS.

### Меню на десктопе

`.side-menu` вынесено из `.header` в `body` — чтобы на десктопе меню могло стать отдельной grid-колонкой, а не оверлеем.

**Escape** закрывает открытое меню и возвращает фокус на бургер.

### Скролл-лок

Блокировка скролла при открытом меню — только на мобильном (`< 640px`). На планшете по требованию макета контент скроллится.

### Hover только на устройствах с курсором

Для пунктов меню hover-эффект обёрнут в `@media (hover: hover)` — на тач-устройствах он не срабатывает (нет «залипания» при тапе).

## JavaScript-модули

### `Hamburger`

Управляет состоянием бокового меню:

- открытие/закрытие по клику на бургер;
- синхронизация `aria-expanded`, `aria-hidden`, `aria-label`;
- закрытие по **Escape** с возвратом фокуса на кнопку;
- опциональный скролл меню в начало при закрытии.

### `AdjustLastRow`

Скрывает элементы последней строки Grid, если она неполная.
Решает задачу «висящей» неполной строки в каталогах карточек.

Алгоритм:

1. Читает `grid-template-columns` через `getComputedStyle`.
2. Вычисляет `totalItems % columns` — количество элементов
   в последней строке.
3. Если остаток > 0 — скрывает их через `display: none`.
4. `ResizeObserver` пересчитывает при изменении ширины контейнера.

Пример:

```js
import AdjustLastRow from './modules/adjust-last-row.js';

const adjuster = new AdjustLastRow('.cards', '.cards__item');
```
